# Unseenet node

A node of [Unseenet](https://unseenet.org), a Usenet-style discussion network
over Tor onion services: chat, threaded discussion, feeds and private posts on
nodes anyone can run. No public IP, no port forwarding, no domain.

Built on the project's signed image `ghcr.io/unseenet/node`. See the
Documentation tab ([DOCS.md](DOCS.md)) for setup.

**Pre-alpha** - not security reviewed.
