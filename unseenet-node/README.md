# Unseenet node

Makes your Home Assistant machine one more node of
[Unseenet](https://unseenet.org) - the shared, Usenet-style discussion network
over Tor onion services: chat, threaded discussion, feeds and private posts on
nodes anyone can run. It joins the existing network; it is not a chat server of
your own. No public IP, no port forwarding, no domain.

Built on the project's signed image `ghcr.io/unseenet/node`. See the
Documentation tab ([DOCS.md](DOCS.md)) for setup.

**Pre-alpha** - not security reviewed.
