# Changelog

## 0.1.0

- First version, on `ghcr.io/unseenet/node:0.7.0`.
- Every setting of `node.toml` is an option: the everyday ones shown, the rest
  under "Show unused optional configuration options".
- The node peers by itself (`auto_peers`); particular peers, what the node
  carries and spam reports are set in the Configuration tab.
